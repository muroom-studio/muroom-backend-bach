## 부록 — Monte의 역질문에 대한 답 (2026-08-03 대화 요약)

- **Q2(GiST가 뭐야)**: 공간 데이터용 인덱스(B-tree는 "크다/작다"만 다루므로 좌표 포함/교차 질의에 무력). `CREATE INDEX ... USING GIST (location)` 한 줄이면 됨. 현재 130건 규모에선 불필요하고, 성장 시 1순위 개선 과제로 서술하면 됨.
- **Q17(가격 이중 구현)**: 정렬은 SQL(`min(room.basePrice) coalesce studioPrice.minPrice`), 표시는 Java(`IntSummaryStatistics` + 조건부 폴백) — 일부 룸만 가격이 null인 스튜디오에서 정렬 순서와 표시 가격이 어긋날 수 있음. 실사용 규모에선 미발현.
- **Q24(private GET URL)**: 서버가 presigned GET을 생성해 주는 방식은 표준적이고 올바름 — inquiry 모듈이 이미 같은 패턴(`getViewUrl` PRIVATE) 사용 중. 잘못된 설계 아니고 단지 미구현.
- **Q18(콜드스타트 측정)**: ✅ 2026-08-03 로컬 근사 측정 완료 — **워밍업 유무 차이 오차 범위**(첫 요청 74 vs 80ms). 결론: 프로드 콜드스타트는 환경 요인(t4g CPU·원격 풀·ALB 타이밍) 지배 [추론], 대책의 본질은 readiness 게이팅(정합성). 상세: evidence/coldstart-local-measurement.md.
